# Hanbdall-7Meter

**7-Meter-Duell** — ein kleines Handball-Spiel als einzelne HTML-Datei: Der klassische Elfmeterschießen-Aspekt, Werfer gegen Torwart.

## Lokal spielen

Keine Installation nötig. Einfach `handball-7meter.html` herunterladen (auf GitHub: Datei anklicken → „Download raw file") und per Doppelklick im Browser öffnen (Chrome, Firefox, Edge — auch offline).

## Steuerung

- Maus bewegen (oder Touch) = zielen
- Maustaste / Leertaste halten = Wurfkraft aufladen
- Loslassen = werfen
- `R` = neue Runde

10 Würfe pro Duell. Der Torwart liest mit jedem Wurf besser und reagiert schneller. Zu schwache Würfe kommen nicht an, Paraden und Pfosten zählen nicht als Tor.
